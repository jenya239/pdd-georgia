# Билеты ПДД Грузии, категория B/B1 — локальная копия (только для личного использования)

- **Источник:** https://teoria.on.ge/tickets/2 (категория «B, B1»), разбивка по 32 темам `https://teoria.on.ge/tickets/2/{topic}?page=N`.
- **Получено:** 2026-10-20, страницы 20:57–21:02, картинки до ~21:25 (Asia/Tbilisi, UTC+4).
- **Способ:** обычные HTML-страницы со списками билетов, которые сайт отдаёт без входа. Язык переключается cookie `exam-settings={"category":2,"locale":"ru"|"ka"|"en",...}` — так же делает переключатель языка на самом сайте. Правильный ответ виден в разметке (`data-is-correct-list="true"`).
  - Скорость: один запрос в ~1,2 с, обычный браузерный User-Agent. Логин, капчи и блокировки не обходились: их и не было. my.sa.gov.ge не трогали.
  - Всего 160 страниц со списками (ru/ka/en) и 524 картинки (~1 запрос/с).
  - 10 картинок в первый раз вернули Cloudflare 522; повторная попытка прошла, в итоге 524/524.
- **Скрипты** (`tools/pdd/tickets/`): `scrape.py` (страницы → `data/tickets/raw/`, в git не попадает), `parse.py` (→ `parsed_all.json`, все 3 языка), `fetch_images.py` (→ `images/`), `build_tickets.py` (→ `tickets_ru.json` + `stats.json`; после автоматического разбора применяет проверенные поправки из `manual_fixes.json`). Воспроизводимость проверяет `tests/py/test_tickets_build.py`.

## Происхождение
- Вопросы, ответы и картинки, судя по всему, взяты из базы Агентства обслуживания МВД (drv.ge прямо пишет, что берёт их «из открытой базы вопросов Сервисного агентства»). Пояснения, переводы и подборка — teoria.on.ge.

## Схема `tickets_ru.json`
```
{ "meta": { source, fetched, count, episodes_index: [{block, title, episodes:[E..], keys:[L36, A1.3, AOC, X ...]}] },
  "questions": [ {
    "id": 334,                       // номер билета на teoria.on.ge
    "source_url": "https://teoria.on.ge/tickets?ticket=334",
    "category": "B,B1",
    "topic_id": 1, "topic_ru": "...", "topic_ka": "...",
    "question": "текст (ru)",
    "answers": [{"n":1,"text":"..."}, ...],      // 2–4 варианта
    "correct": 3,                                 // n правильного ответа
    "image": "images/<hash>.jpg" | null, "image_url": "http://teoria.on.ge/files/new/<hash>.jpg",
    "explanation_ka": "пояснение (только по-грузински) со ссылкой на закон" | null,
    "law_refs":  [{"article":"36","paragraph":4}],          // Закон «О дорожном движении»
    "annex_refs":[{"annex":1,"items":["5.11"]}],            // приложения (знаки/разметка)
    "aoc_refs":  [],                                        // КоАП (в базе B не встретилось)
    "episodes": ["E066"],                                   // серии из ../structure.md §4
    "episodes_method": "law_reference" | "topic_fallback",
    "flags": [],                                            // no_explanation, ru_text_is_georgian_untranslated, image_missing
    "ka": {"question","answers"}, "en": {"question","answers"}  // тот же вопрос на ka/en (тот же порядок ответов, тот же correct)
} ] }
```

## Привязка к закону и сериям
- Статьи вытаскиваются регуляркой из грузинского пояснения: шаблоны «N-ე მუხლის», «მე-N მუხლის» с «… პუნქტის», «პირველი/მე-N დანართის» и номера знаков/разметки вида 5.11. Ссылка на закон или приложение нашлась у **769** вопросов.
- У остальных **152** (первая помощь, физика торможения, безопасность, эко-вождение, единичные случаи) серии поставлены по теме teoria.on.ge (`topic_fallback`).
- Серии внутри многосерийного блока выбираются по номеру пункта статьи: пункт p из P пунктов → серия ⌊(p−1)·n/P⌋. Это эвристика, при раскадровке её надо проверять.
- Ст. 5 (термины) идёт по алфавиту, поэтому такие вопросы привязаны ко всем 8 сериям словаря (E003–E010).
- 188 вопросов попадают в несколько строк плана: в пояснении несколько статей.

## Проблемы качества данных
1. **51 вопрос по эко-вождению (тема 32, id 1742–1792) не переведён:** в ru и en вместо перевода грузинский текст, пояснений нет («განმარტება მალე დაემატება» = «пояснение скоро будет»). Пометки `ru_text_is_georgian_untranslated` и `no_explanation`. Русский текст нужно брать из другого источника или переводить самим (с пометкой).
2. **Пояснения есть только по-грузински**, во всех языках (сайт сам об этом пишет). Русских пояснений нет. Номера статей и пунктов в них могут относиться к прошлым редакциям закона, поэтому перед использованием сверять с редакцией 25.06.2026.
3. **Число вопросов (921) не совпадает с официальным/актуальным** (1083 на sa.gov.ge, 898 по drv.ge). Возможно, часть вопросов устарела или выведена из базы.
4. Русские формулировки — перевод сайта/Агентства. Встречаются кальки с грузинского, например «не сдвинуть с места».
5. Битых картинок нет (524/524, все JPEG). Вопросов без правильного ответа нет.
