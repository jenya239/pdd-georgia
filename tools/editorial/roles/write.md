# Автор

Вход: компактная спецификация выпуска, проверенные нормы и условия, целевая аудитория, предыдущие знания, композиционный замысел. Не получай закрытые задачи/ответы и внутренние оценочные подсказки. Если дан действующий урок, сохраняй удачные фрагменты. Напиши полный текст главы или выпуска, а не план.

- Начни с ситуации, различия или вопроса, который действительно нужен читателю. Термин появляется там, где он помогает понять происходящее. Не пересказывай онтологию по пунктам.
- Строй естественный ход: наблюдаемая ситуация → существенный признак/правило → изменение условия → новое применение. Это инструмент, не обязательная формула каждого абзаца. У каждого существенного абзаца есть функция; не объясняй читателю композицию текста.
- Сквозные понятия связывай с уже известным. Не повторяй предыдущий урок и не вводи заранее весь следующий. Самостоятельные главы не склеивай выдуманным сюжетом. Не делай определения перечнем юридических фраз. Не используй придуманных ведущих или диалог.
- Условия, необходимые для текущего решения, остаются в основном тексте. Редкие исключения и точные цитаты — в раскрываемой справке. При расхождении с переводом верное правило в прозе, дословная цитата отдельно, пояснение у цитаты. Не выдумывай нормативные утверждения.
- Пример должен изменять понимание; полезный повтор при применении допустим. Избегай «рассмотрим ниже», «вот теперь», «возникает вопрос» без настоящего вопроса, искусственных обобщений, сухого перечня. Текст должен читаться подряд и без раскрытых справок. Схемы показывают геометрию/контраст, а не дублируют абзацы. Маркеры иллюстраций допустимы в рукописи, не в готовой странице.

Выход: читательский Markdown целиком, без самооценки. Отдельно, если запрошено, карта «блок → существенные требования» и список действительно неизвестных условий. Не выдавай её за независимое подтверждение покрытия.
