# Комплект выпуска: задания, разборы, схемы и сценарии

Вход: замороженный выбранный урок, нормы, онтология, действующие карточка/вопросы/разборы/сценарии. Сначала инвентаризация и сверка, затем только необходимые изменения. Валидация независима от авторства материалов.

## Задания и билеты

- Сохраняй `content/checkitems/epNN.json` и стабильные ID `o-epNN-*`. Проверяй ситуацию, варианты, верный индекс, объяснение, цитаты, нормы, концепты, distractors и фигуру. Новый вопрос должен проверять применение знания, а не угадывание слова. Не заменяй существующие вопросы несколькими иллюстративными примерами. Новые отложенные задачи держи отдельно от учебных.
- Назначение официальных билетов берётся из онтологии/отчёта сборки, не руками. `node tools/lesson-gap.mjs` показывает пропуски. Проверь каждый уже существующий разбор назначенного билета, допиши пропущенные. Не создавай для неназначенных или заблокированных. Официальный вопрос, варианты, изображение и ответ не редактируй; обнаруженный конфликт с законом зафиксируй отдельно, не маскируй.
- `content/breakdowns/<id>.json`: 60–170 слов своего текста без цитат; `steps` 2–3 шага, решающие этот вопрос; `quotes` дословно с ID нормы; `why_not` ровно неверные индексы и соответствующие `mc` из онтологии; `trap` одна конкретная ловушка; `concepts` уже введённые. Не пересказывай урок. При кривом переводе сначала правильное правило, краткая оговорка у цитаты/в ловушке. Ответ и основания сверяй с законом и реальным изображением.
- Типичные ошибки и `content/critiques/epNN.json` сохраняют связь с нормой, билетом, якорем, концептом. Не изобретай новую сущность или ID ради отчёта. `content/episodes.json`: lead/points/pitfalls/core_note и ссылки согласованы с уроком, «Главное» не второй урок.

## Схемы

Проверь фактический активный генератор. Используй существующие SVG/знаки из `content/assets/signs/` и механизм сборки. Направления, стороны, ближайший край, границы, размеры, полосы и сигналы соответствуют ситуации; один изменённый признак не меняет остальные случайно. Не дублируй id SVG, проверь ссылки `url(#…)`. Посмотри готовую страницу: схема читается без поясняющего служебного текста, не обрезана, подпись не спорит с законом. Не добавляй стоковые изображения вместо точной геометрии.

## Теоретический ролик

Для каждого ep01–ep08 подготовь полный `video/episodes/epNN/{scenes,boards}.py` в действующем интерфейсе (или проверь и сохрани хороший существующий). Читай раздел «Ролик» `docs/lesson-prose.md` и реальный движок. `BEATS`, `GLOSS`, `CLOCK`, `LOC`, `VOICES`, `NAMES`, `ROLES`; один диктор `n`, имя пустое; такты и ключи досок в существующем формате. Для нового сценария не вводи персонажей/чат. Ситуация → выбор → правило → изменение одного условия → новая ситуация с паузой до ответа. Покрой каждый пункт «Главного»; не читай статью подряд. Речь, субтитры, акцент в кадре, знак и результат совпадают; номера норм/знаков произносятся словами. Цитаты на доске дословные. Функция `b_<ключ>` существует для каждого такта; акцент появляется в нужную фразу. Проверяй доски/стиллы при доступном окружении, не переписывай `video/engine` и `cast.py`.

## Видео по билетам

Отдельный сценарий `video/episodes/epNN-tickets/`: только назначенные официальные билеты, реальные картинки/варианты, объяснение решающего отличия. Можно группировать родственные ситуации, но зафиксируй, где покрыт каждый назначенный билет, не повторяй весь урок и не выдавай один билет за все остальные. При нуле назначений отметь `not-applicable`. Сохрани текстовые разборы. Не подменяй теорию роликом по билетам.

## Статусы и проверки

Сценарий, визуальные кадры, озвучка и опубликованный mp4 — разные артефакты. Не перезаписывай существующие timeline/mp4 и не убирай `video_note` только потому, что сценарий исправлен. Рендер — отдельная разрешённая задача; если разрешён, действующий `video/render.py <id> tts/still/video`, просмотр кадров, ffprobe (картина и звук), только затем публикация согласно AGENTS. Для эпизодов 1–3 старые mp4 с персонажами; для ep04 известны старые ошибочные формулировки; ep04-tickets — старый последовательный разбор. Перепроверь актуальность этих сведений.

Выход: реальные изменённые файлы, матрица `norm/concept → lesson → checkitem/ticket → breakdown → scene/board`, перечень непокрытого, результаты проверок и отдельные статусы текста, сценария и медиа. Не называй сценарий готовым видео. Не объявляй проверку пройденной без фактического запуска.
