знак 5.11.1

Приложение 1 (дорожные знаки)

Закон Грузии «О дорожном движении» № 1830-რს, консолидированная редакция 25.06.2026 (Matsne, публикация 36). Юридическую силу имеет грузинский текст, русский — перевод. Источник: Matsne (рус.), Matsne (груз.).

Текст (рус., дословно)

5.11.1. «Дорога с полосой движения, предназначенной для такси (категория M1)» – дорога, по которой такси (категория M1) двигаются по специально выделенной полосе навстречу общему потоку транспортных средств, и которая одновременно является дорогой с полосой, предназначенной для движения маршрутных транспортных средств, обозначенных дорожным знаком 5.11. Действие дорожного знака 5.11.1 распространяется на полосу движения, на которой он стоит. Этот знак не обязывает такси (категория M1) двигаться только по указанной полосе.
