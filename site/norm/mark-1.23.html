Приложение 2 (дорожная разметка)

Закон Грузии «О дорожном движении» № 1830-რს, консолидированная редакция 25.06.2026 (Matsne, публикация 36). Юридическую силу имеет грузинский текст, русский — перевод. Источник: Matsne (рус.), Matsne (груз.).

Текст (рус., дословно)

1.23. Обозначает полосу, предназначенную для движения маршрутных транспортных средств. Дорожная разметка, нанесенная для выделения полосы, предназначенной для движения маршрутных транспортных средств, может быть желтого цвета.
