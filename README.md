# ПДД Грузии: учебный сайт (черновик)

Статический сайт (HTML/CSS/JS без сборщика). Не опубликован.

## Запуск локально
```
cd /workspace/pdd_georgia/site
python3 -m http.server 8000
# открыть http://localhost:8000/
```
С `file://` не работает: данные загружаются через `fetch`.

## Пересборка данных
`python3 tools/build.py`. Скрипт читает `../tickets/tickets_ru.json`, `../structure.md`, `../sources/*` и `tools/episodes_src.json` (тексты выпусков: ключевые пункты, ссылки, цитаты), а записывает `data/tickets.json`, `data/episodes.json` и копирует картинки в `img/`.
Видео: `media/epNN.mp4` (видео H.264 скопировано без перекодирования, звук пережат в AAC 96k, `+faststart`), постеры — `media/epNN.jpg`.

## Новый выпуск
Выпуск бывает двух видов (`kind` в `data/episodes.json`, вычисляется в сборке):
- **видео** — `media/epNN.mp4` и `media/epNN.jpg`;
- **текст** — урок `lessons/epNN.html` (фрагмент HTML; маркер `<!--AFTER-TICKETS-->` делит его на теорию до билетов и «наши вопросы» после), картинки — в `lessons/epNN/`. Урок ep04 генерирует `../ep04_text/make_lesson.py`.

Затем:
1. Добавьте запись в `tools/episodes_src.json`: plan (E-номера), points, quote_refs, ticket_refs, а также `teaches` / `include` / `exclude` / `pitfalls` (см. ниже).
2. Запустите `python3 tools/build.py`.

## Билет → урок (поле `lesson`)
У каждого билета не больше одного основного урока. Поле `lesson` вычисляет сборка (`tools/assign.py`, в `../tickets/tickets_ru.json` оно не пишется):
1. **Основное правило** билета — первая ссылка на закон (статья, пункт, грузинский подпункт), а если её нет — первый пункт приложения (знак, разметка).
2. Урок — **самый ранний** выпуск, у которого `teaches` покрывает это правило. Спецификации: `"ст. 39"`, `"ст. 39 п. 1"`, `"ст. 34 п. 9 д"`, `"прил. 1 1.1"`.
3. `include` и `exclude` — ручные поправки по номерам билетов. Их добавляют только после проверки, что урок действительно объясняет (или не объясняет) ответ.
4. Билеты, которые не объяснил ни один урок, остаются без `lesson`.

Поле `episodes` (тематические ссылки на билеты) остаётся как было. `pitfalls` — заметки «почему здесь ошибаются» по правилу. Они берутся только из текста урока и показываются только у билетов этого урока (поле `why`).

## Прогресс, накопительная проверка, ошибки
Прогресс хранится только в браузере (`localStorage`):
- `pddge.progress.v1` — по билету: попытки, верные, ошибки, серия верных подряд, дата последней ошибки, выбранные неверные варианты;
- `pddge.runs.v1` — результаты накопительных проверок;
- `pddge.cumrun.v1` — незаконченные проверки;
- `pddge.settings.v1` — настройки.

Страницы:
- `check.html?lesson=epNN` — накопительная проверка: все билеты этого урока и предыдущих. Сначала идут новые билеты, потом прежние вперемешку (порядок можно сменить). Проверку можно продолжить после перезагрузки, есть история результатов.
- `errors.html` — типичные ошибки (рейтинг, по урокам, темам, правилам) и «Разобрать ошибки»: билет считается исправленным после 2 верных ответов подряд.
- Экспорт и импорт прогресса в JSON — на главной и на странице ошибок. При импорте данные сливаются: счётчики складываются, дата берётся у более свежей записи.

## Код
- `assets/lib/*.mjs` — доменная логика: чистые ES-модули без DOM и без фреймворков. Хранилище подключается через адаптер `createStore(backend)`: в браузере это `localStorage`, в тестах — `memoryBackend()`.
- `assets/ui/*.mjs` — небольшие DOM-виджеты.
- `assets/common.js` — общий код страниц (навигация, язык, вывод вопроса).
- `tools/assign.py`, `tools/episodes.py` — чистые функции сборки. `tools/build.py` — ввод-вывод.

## Тесты
```
node --test tests/js/          # доменные модули (Node 18+)
python3 -m pytest -q tests/py  # функции сборки
```
Сквозные браузерные проверки (Playwright) лежат вне репозитория: `../site_test/test.py` и `../site_test/test_ep04.py`. Скриншоты сохраняются туда же.

## Структура
- `index.html` — выпуски и план E001–E107
- `episode.html?id=ep01` — видео или текстовый урок, ключевые пункты, текст закона, билеты
- `check.html?lesson=ep04` — накопительная проверка
- `errors.html` — типичные ошибки и их разбор
- `practice.html` — самопроверка: все вопросы, тема, серия, ошибки, нерешённые
- `exam.html` — пробный экзамен
- `about.html` — источники и ограничения
- `assets/` — CSS и общий JS; `data/` — JSON; `img/` — картинки к билетам; `media/` — видео; `tools/` — сборка
